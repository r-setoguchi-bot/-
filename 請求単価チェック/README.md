# 請求単価チェック

kintone「契約管理」アプリの各レコードについて、添付された見積りファイル（PDF/Excel/画像）から
AIで金額を読み取り、現在の「請求単価」フィールドと一致しているかを確認するツールです。

**瀬戸口秘書ボットとは完全に別・独立したプロジェクトです。** 秘書ボットのGASプロジェクトやスプレッドシートには一切触れません。

**kintoneへの書き込みは行いません。** チェック結果は
- このプロジェクト専用に自動作成されるスプレッドシート（初回実行時に作成）
- 実行者宛のメール（要確認の項目のみ）

に出力されるだけです。

## セットアップ手順

### 1. 新しいGoogle Apps Scriptプロジェクトを作成する

1. https://script.google.com/home にアクセス
2. 「新しいプロジェクト」を作成
3. プロジェクト名を「請求単価チェック」などに変更
4. エディタ内の `コード.gs`（または `コード.js`）の中身を、このフォルダの `コード.js` の内容に置き換える
5. 左メニューの「プロジェクトの設定」の歯車アイコンを開き、`appsscript.json` をエディタで表示できるようにする（「マニフェスト ファイルを表示する」にチェック）→ このフォルダの `appsscript.json` の内容で上書き

### 2. スクリプト プロパティを設定する

「プロジェクトの設定」→「スクリプト プロパティ」で以下を追加：

| プロパティ名 | 値 |
|---|---|
| `KINTONE_SUBDOMAIN` | kintoneのサブドメイン（`https://xxxx.cybozu.com` の `xxxx` 部分） |
| `KINTONE_KEIYAKU_APP_ID` | 契約管理アプリのアプリID |
| `KINTONE_KEIYAKU_API_TOKEN` | 契約管理アプリのAPIトークン（レコード閲覧・アプリ管理の権限が必要） |
| `GEMINI_API_KEY` | Gemini APIキー |

（任意）通知先メールを実行者以外にしたい場合は `NOTIFY_EMAIL` を追加。
（任意）見積り/請求単価のフィールドが自動判定できない場合のみ `KINTONE_KEIYAKU_MITSUMORI_FIELD` / `KINTONE_KEIYAKU_TANKA_FIELD` を追加。

### 3. 動作確認

1. 関数選択のドロップダウンで `checkBillingRates` を選ぶ
2. 「実行」を押す（初回は権限承認が必要）
3. 実行者のメールに結果が届き、初回のみ「請求単価チェック結果」という新しいスプレッドシートが自動作成される

### 4. 定期実行したい場合

`setupBillingRateCheckTrigger` を1回だけ手動実行すると、毎日午前8時に自動でチェックが走るようになります。
